# About the Project

## 8-Bit Arithmetic Logic Unit (ALU)

This project is an 8-bit Arithmetic Logic Unit (ALU) developed as a fundamental processing unit for a custom-built 8-bit computer. The ALU is responsible for processing 8-bit binary data and performing arithmetic and logical operations required by the computer.

The ALU was designed and implemented using individual digital logic ICs, registers, adder ICs, and supporting components. Instead of relying on a single dedicated ALU chip, the circuit was built from basic building blocks to understand the internal operation and data flow of an ALU at the hardware level.

## Architecture

The ALU operates on 8-bit data stored in registers. The input data is transferred through the registers and processed by the arithmetic and logic circuitry. The resulting 8-bit output can then be stored back into a register or passed to other parts of the computer.

### Main Components

- 8-bit Registers
- Binary Adder ICs
- Logic Gate ICs
- Control Signals
- LEDs for visual output
- Breadboard and supporting components

## Operations

The ALU is designed to support fundamental operations such as:

- Addition
- Subtraction
- Logical operations
- Data transfer and processing

The exact operations are controlled using digital control signals generated by the computer's control circuitry.

## Purpose

The primary purpose of this project is to gain practical experience in digital electronics and understand how the fundamental components of a processor work together. Building the ALU from individual ICs provides a hands-on understanding of binary arithmetic, registers, data paths, control signals, and digital logic.

## Project Documentation

This repository contains the circuit diagrams, photographs, videos, datasheets, and other documentation related to the development and testing of the 8-bit ALU.

This ALU forms one of the core building blocks of the custom 8-bit computer and demonstrates how complex computing operations can be constructed from basic digital logic components.
